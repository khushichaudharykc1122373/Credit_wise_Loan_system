# 💳 Credit Wise Loan System

## 📌 Project Overview

Credit Wise Loan System is a data-driven project designed to analyze loan applications and predict whether a loan is likely to be approved based on various applicant and financial factors.

The project focuses on understanding loan application data, performing data preprocessing and exploratory data analysis, and building a machine learning model for loan approval prediction.

## 🎯 Objectives

- Analyze loan application data
- Clean and preprocess the dataset
- Perform Exploratory Data Analysis (EDA)
- Identify important factors affecting loan approval
- Build a machine learning model for prediction
- Evaluate the performance of the model

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📊 Project Workflow

1. Data Collection
2. Data Cleaning
3. Data Preprocessing
4. Exploratory Data Analysis
5. Feature Selection
6. Model Building
7. Model Evaluation
8. Loan Approval Prediction

## 🔍 Key Features

- Handles missing values and inconsistent data
- Visualizes important patterns in loan applications
- Analyzes applicant and financial factors
- Uses Machine Learning for loan approval prediction
- Evaluates model performance using suitable metrics
